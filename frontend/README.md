# Studio Elen Gomes — Frontend

Frontend Next.js + React + TypeScript do sistema Studio Elen Gomes.

## Desenvolvimento

1. Copie `.env.example` para `.env.local`.
2. Garanta que o backend esteja em `http://localhost:8080`.
3. Instale as dependências com `npm install`.
4. Rode `npm run dev`.

A aplicação usa a API REST do Spring Boot e autenticação JWT.

## Etapa 2 — identidade visual
- Login com a fotografia de referência do Studio Elen Gomes como background.
- Logo oficial aplicada no login, sidebar e navegação mobile.
- Nova aba Financeiro integrada à API REST.
- Agenda com registro de pagamento, cancelamento e acesso rápido ao financeiro.
